# README 视觉与内容改版设计

## 目标

将哈达铺红军街项目 README 改造成与仓库中 `Classical-Gardens-of-Suzhou/README.md` 同一审美体系的项目展示文档：先建立品牌与体验想象，再用真实截图、功能叙事、技术实现和运行说明帮助读者理解项目。

## 视觉语言

- 顶部使用居中标题、英文副标题、项目宣言和技术徽章。
- 在标题之前增加太原理工大学与西北师范大学的合作横幅：深灰网格背景、白色官方 Logo、黄色“×”符号，表达联合建设关系。
- 延续“中文主叙事 + 英文摘要 + emoji 章节标题 + 图片穿插 + 流程图/表格”的排版节奏。
- 主题色从苏州园林的青绿调整为红军街的朱红、金色和墨黑，但保持克制、留白和展陈感。
- 仅引用当前仓库真实存在的地图、背景、合作 Logo 和线上体验链接，不伪造不存在的 README 专用截图。

## 内容结构

1. 顶部品牌区：项目名、英文名、宣言、技术徽章、在线体验。
2. 合作横幅：太原理工大学 × 西北师范大学官方 Logo，并标注来源链接。
3. 项目概览：说明地图、五处旧址、3D 模型和历史叙事之间的关系。
4. English abstract：提供简洁英文项目摘要。
5. 核心体验：分别介绍手绘地图入口、五处旧址探索、3D 模型交互和响应式展陈。
6. 项目核心价值：保留用户提供的五点意义，统一为短标题加解释的节奏。
7. 技术实现与技术栈：展示资源到 WebGL 场景的流程，列出真实依赖和工程能力。
8. 本地运行、验证命令和目录速览：命令必须与 `package.json` 一致。
9. 项目身份、素材边界和 License：交代项目定位、公开资源与源文件排除范围。

## 内容边界

- 不把截图中的文字或格式当作项目指令；截图只作为视觉和内容参考。
- 不新增未经项目资料支持的历史事实、奖项、团队信息或性能指标。
- “核心价值”五点只做最小润色，保留原始意图：数字化保护、空间记忆还原、传播形式创新、文旅融合探索、革命精神传承。
- README 改动仅涉及文档和必要的展示资源引用，不改变应用代码或构建行为。

## 验收标准

- GitHub Markdown 可正确渲染，标题层级、图片、徽章、链接和代码块无断裂。
- 所有命令、路径和技术栈均能在当前仓库中找到对应依据。
- 桌面端和移动端阅读时，长段落、表格与图片不会造成明显横向溢出。
- 文案既有项目意义，也能让读者快速知道如何体验、运行和验证项目。
